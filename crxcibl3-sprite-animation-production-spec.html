Tool Chain (FOSS only)

Replace Leonardo.ai with this fully free, locally-run pipeline:

StepToolPurposeLicense

or ComfyUI — both free, run locally on GPU or CPU		 Generate base pose reference image from prompt. Use anything-v3 or DreamShaper checkpoint + Pixel Art XL LoRA for pixel style. AGPL-3
2 · Pixelate Aseprite (compile from source free) or LibreSprite (binary free)
LibreSprite = Aseprite fork, MIT licensed, binary downloads available		 Import SD output, resize to target frame size with Nearest Neighbor, quantize palette to 12–16 colors, hand-correct outlines. MIT
3 · Animate LibreSprite (same tool)

5 · Import Godot 4.7 editor (or --headless --import in CI) Drop PNG into correct res://assets/sprites/ subfolder. Godot auto-imports with Nearest filter on next boot or CI import step. MIT

All sprite sheets are horizontal strips: N frames × frame_width pixels wide, frame_height pixels tall. One animation per file. AnimationLoader.gd reads frame count from sheet width ÷ frame_w automatically.

Style Anchor String

Append to every Stable Diffusion prompt:

16-bit pixel art, top-down 3/4 angle game sprite, flat color fills, hard black outlines, no gradients, no anti-aliasing, limited retro palette of 12-16 colors, muted gritty urban tones, transparent background, single character centered, Metal Slug sprite style

Recommended SD settings: Steps 30, CFG 7.5, Sampler DPM++ 2M Karras, 512×512 output then resize to target in LibreSprite with Nearest Neighbor.

Step-by-Step Workflow Per Character

#StepTime (est.)Notes
1 Generate idle reference in SD 10–20 min Run ~20 generations, pick best pose. Save at 512×512. You only need 1 good reference image per archetype base.
2 Import into LibreSprite, resize to frame size 5 min File → New canvas at frame size (e.g. 32×48). Paste SD output as layer. Scale down with Nearest Neighbor. Clean up outline pixels manually.
3 Trace + simplify to 12–16 color palette 20–30 min Use Palette → Quantize. Delete the SD layer. Redraw clean pixel art over the trace using solid colors only. No anti-aliasing.
4 Animate remaining frames (walk, shoot, downed) 2–4 hrs Enable onion skin. Duplicate idle frame as base. Adjust limb positions per frame. Walk cycle: contact→down→passing→up→contact. 12 frames = 2 full stride cycles.
5 Export as horizontal strip 2 min File → Export Sprite Sheet. Layout: Horizontal strip. Check "Trim cels." Output: PNG. Filename matches animation name (e.g. walk_right.png).
6 Place in correct Godot folder 1 min Drop into godot/assets/sprites/heroes/<variant_id>/. Run godot --headless --path godot --import or just open editor. AnimationLoader auto-picks it up at next boot — no code changes needed.
7 Palette variants for same archetype 15 min each In LibreSprite: Edit → Replace Color for each skin/clothes color. Save as separate folder. 3 variants per archetype = 3 palette swaps, not 3 full redraws.

12-Frame Walk Cycle Breakdown (Metal Slug reference)

Walk right: frame-by-frame body position for 32×48 sprite. Right = positive X direction.

FramePhaseRight legLeft legTorsoWeapon arm
1Contact RForward, foot flatBack, toe pushUprightForward
2Down RUnder body, knee bentLiftingSlight dip (−1px)Mid
3Passing RPlanted, straightPassing through centerTallest (+1px)Back
4Up RBehind, pushingSwinging forwardRisingForward
5Contact LBack, toe pushForward, foot flatUprightBack
6Down LLiftingUnder body, knee bentSlight dip (−1px)Mid
7Passing LPassing through centerPlanted, straightTallest (+1px)Forward
8Up LSwinging forwardBehind, pushingRisingBack
9–12Repeat 1–4Second stride cycle — identical to frames 1–4

Key rule: body height oscillates ±1 pixel per frame. Arms counter-swing to legs. Weapon stays level regardless of body bob. This is what makes Metal Slug feel snappy vs. floaty.

How the Code Picks Up New Art (no changes needed)

## When you drop idle.png into: ## godot/assets/sprites/heroes/enforcer_ghost/idle.png ## AnimationLoader.gd automatically detects it: var sprite_dir := "res://assets/sprites/heroes/enforcer_ghost/" var sf: SpriteFrames = ANIM_LOADER.build_frames( ANIM_LOADER.player_anims(sprite_dir) ) ## → builds SpriteFrames from all PNGs found in that folder ## → assigns to AnimatedSprite2D child "Anim" ## → hides static Sprite2D "PlayerSprite" automatically ## Nothing else to change. Zero code edits per character.

If only some animations exist (e.g. only idle.png is ready), AnimationLoader creates dummy 0-frame entries for missing states. The game keeps running — missing states silently show nothing while the present ones animate normally.
