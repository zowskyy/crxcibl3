CRXCIBL3 — Voiceover WAV delivery manifest
==========================================

Drop recorded WAVs into the folders below. Paths match JSON `audio` keys in
`godot/data/emperor_scene.json` and `godot/data/blackwood_scene.json`.

Format spec
-----------
- Sample rate: 44.1 kHz
- Bit depth: 16-bit or 24-bit
- Channels: mono or stereo
- Peak normalize: -3 dBFS
- Format: uncompressed WAV

If a file is missing, CutsceneDirector logs a warning and uses the JSON
`duration` field as a silent fallback.
